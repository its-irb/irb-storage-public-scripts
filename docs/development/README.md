# Documentación para desarrollo

Documentación para comprender, mantener y ampliar el proyecto.

Esta capa documental se incorporará progresivamente. Consulta
`docs/documentation-methodology.md` para conocer la convención de capas,
audiencias y reglas de mantenimiento.

El contenido de esta carpeta debe permitir que un desarrollador comprenda el
proyecto, su intención, su estructura y sus principales flujos, y pueda
mantenerlo o ampliarlo sin tener que leer previamente todo el código ni
consultar la documentación para agentes o usuarios.
