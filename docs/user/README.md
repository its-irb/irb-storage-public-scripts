# Documentación para usuarios

Guías orientadas a los objetivos de las personas que utilizan el producto.

Esta capa documental se incorporará progresivamente. Consulta
`docs/documentation-methodology.md` para conocer la convención de capas,
audiencias y reglas de mantenimiento.

El contenido de esta carpeta debe permitir que un usuario instale, acceda,
configure y utilice el producto, y resuelva los problemas habituales, sin
depender de la documentación para desarrolladores o agentes.
