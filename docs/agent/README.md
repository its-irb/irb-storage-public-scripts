# Documentación para agentes

Contexto operativo para agentes que trabajan sobre el repositorio.

Esta capa documental se incorporará progresivamente. Consulta
`docs/documentation-methodology.md` para conocer la convención de capas,
audiencias y reglas de mantenimiento.

Los documentos de esta carpeta deben ser pequeños, modulares y cargables bajo
demanda, para que un agente pueda localizar y modificar el código con seguridad
sin depender de las capas de desarrollo o de usuario.
